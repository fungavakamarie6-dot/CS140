Questions

  1. What is normal flow in HTML?
    Normal flow is the default layout. Block boxes (like paragraphs and headings) stack from top to bottom, and inline content (like text and links) runs left to right inside them.
  2. What does float do? Why do you need to clear the float?
    Float takes a box out of normal flow and pushes it to the left or right so text wraps around it. Boxes after it move up beside it, so you use clear to make a box (like a heading) start below the float instead.
  3. What do absolute, fixed, and relative do?
    relative moves a box from where it normally sits, but its original space stays reserved. absolute removes the box from normal flow and places it using top/right/bottom/left relative to the page (or its nearest positioned parent); it scrolls with the page. fixed also removes the box from flow but places it relative to the screen, so it stays in place while you scroll.
  4. How can you make nice navigation buttons for mobile devices?
    Use display: block on the links so each one is a full-width box, then add padding, a large font size, and a background color so the whole button is easy to tap.
