1. Explain the difference between inline, embedded, and external CSS.

An inline CSS is added directly to an HTML element.So, an embedded CSS is written inside the HTML file using a style tag.While an external CSS is written in a sparate CSS file and connected to the HTML page.

2. Explain why you should only use external CSS.

The reason why we use an exteral CSS is because it keeps the HTML code cleaner and more organized. Not only that, it also makes it easier to change the design because you can make changes in one CSS file instead of changing every page.

3. What is a selector used for?

A selector is used to tell CSS which part of the HTML you want to change or style. For example, you can use a selector to change the color, size, or font of a heading or paragraph.
