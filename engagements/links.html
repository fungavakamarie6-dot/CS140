Explain the difference between an absolute link and a relative link. Why would you use relative links?

An absolute linkuses the full web address, like https://www.google.com, so it always points to the same place no matter where the file is located. On the other hand, a relative links uses a path based on your own folder struture, like tags.html or .../projects/definitions.html, so it only works within your own website. You'd use relative links when linking between your own pages because they're shorter to write and they still work correctly even if you move your whole website to a new domain.

List 3 rules with relatives links

  1. Same folder: just use the filename, like structural.html
  2. Going into subfolder: use foldername/filename, like projects/definitions.html
  3. Going up a folder: use ../ before the path, like ../projects/definitions.html

Do links always need to be inside a NAV tag?

No, links don't always need to be inside a nav tag. Nav is meant for a group of navigation links, like menu. A single link inside a paragraphor elsewhere in the main content doesn't need to be wrapped in nav.
