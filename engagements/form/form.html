Questions

1. What does the form's "action" attribute do?

It sets where the form data gets sent when you submit a script or URL. If left out, it sends to the same page.

2. What does the form's "method" attribute do?

It sets how the data is sent, either GET or POST.

3. What is the difference between POST and GET?

Get puts the data in the URL, so it's visible and good for searches. While POST hides the data in the request body, so it's better for passwords and sensitive info.

4. How do you pre-fill a control, and how is that different from a placeholder?

You pre fill with the value attribute. That text is really in the field and gets submitted. A placeholder is just a light gray hint that disappears when you type and is never submitted.
