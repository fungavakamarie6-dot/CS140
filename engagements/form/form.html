Questions

1. What does the form's "action" attribute do?

It sets where the form data is sent when you submit (a URL or script). If left out, it sends to the same page.

2. What does the form's "method" attribute do?

It sets how the data is sent, either GET or POST.

3. What is the difference between POST and GET?

GET puts the data in the URL, so it's visible and good for searches. POST hides the data in the request body, so it's better for passwords and sensitive info.

4. How do you pre-fill a control, and how is that different from a placeholder?

You pre-fill with the value attribute. That text is really in the field and gets submitted (like my email field). A placeholder is a light gray hint that disappears when you type and is never submitted (like my Full Name field).

5. Which form controls did HTML5 add, and which did you use?

HTML5 added input types like email, url, tel, number, range, date, time, color, and search, plus datalist and attributes like required and placeholder. In my form, I used the email and date input types and the placeholder attribute.
