CSS Selectors

List out the different ways to select an item.

You can select an item by its tag name, class, ID, or by targeting it as a child inside another element.

What is the different ways to select an ID and a Class?

An Id can only be used once on a page, while a class can be used on multiple elements at the time.

What is the difference between a SPAN and a DIV tag?

A span is inline and only wraps small pieces of text without breaking the line, while a dic is block level and takes up its own section.

What is the difference between a DIV tag and a Header, MAIN, or FOOTER?

A div has no real meaning on its own, but header, main, and footer are semantic tags that tell the browser what that part of the page actually is.

What are the different ways to select a color?

You can select a color using its name, a hex code, RGB values, or HSL values.
