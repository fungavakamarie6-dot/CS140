Questions

1. Why don't we use the border attribute?

We don't use the border attribute because HTML is meant for structure while CSS handles the design. The border attribute is outdated and only gives you a basic, uncustomizable line, whereas CSS lets you control colors, widths, and styles across your whole site from one file.

2. What is the easiest way to color every other row a different color?

The easiest way is using the CSS pseudo-class tr:nth-child(even). This automatically handles the striping pattern for you so you don't have to manually add classes to every individual row.

3. What does the value in the parentheses mean?

The value in the parentheses tells the browser which specific child elements to target based on their position. For example, even selects every alternative row (2nd, 4th, 6th, etc.). You can also use values like odd to select the 1st, 3rd, and 5th rows instead.
