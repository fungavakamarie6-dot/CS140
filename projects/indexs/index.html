Assignment Questions

  1. What kind of photos are good to encode using JPEG?
    Complex photos with many colors, gradients, and continuous tones, such as real-world photography and landscapes.
  2. What kind of photos are good to encode using GIF?
    Simple graphics with limited colors (up to 256 colors), line art, small icons, or simple animations.
  3. What is unique about the PNG format?
    It supports lossless compression and alpha-channel transparency (allowing smooth background blending).
  4. How do you resize your photo to the size it should be displayed?
    Use an image editing tool (like Photoshop, GIMP, or Photopea) to scale and export the actual pixel dimensions of the image file before adding it to the site, rather than relying only on HTML/CSS resizing.
  5. Why should you resize photos using an image editor rather than HTML/CSS?
    Resizing via HTML/CSS only changes how the browser renders the file—it doesn't reduce file size. Pre-resizing images speeds up page load times and saves bandwidth.
